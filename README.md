This is a monorepo for some commonly used, relatively small packages.

Some times you need hundreds of lines of code to get something done, which is to big to do in every project. It's also to big to put into `utilium`, which is my library meant for lots of trivial things that way I don't have to maintain the same function across dozens of repos. They're too small to dedicate an entire repo, especially considering all the tooling that has to go with it.
